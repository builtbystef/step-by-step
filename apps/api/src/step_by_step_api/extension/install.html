Install the Step by Step extension

This instance serves the extension build that came with it. Recording runs in your own Chrome, so the extension is what records — the app cannot.

Download the extension (version $version)

Chrome $chrome or newer. The same file works in any Chromium browser.

Install it

  1. Unzip the download. Keep the folder somewhere it can stay — Chrome loads it from where it sits, so moving or deleting it removes the extension.
  2. Open chrome://extensions in a new tab.
  3. Turn on Developer mode, at the top right.
  4. Choose Load unpacked, and select the folder you unzipped.

Connect it to this instance

  1. Click the Step by Step icon in the toolbar.
  2. Enter this instance's address and choose Connect.
  3. Chrome asks whether the extension may work on that site. Choose Allow: it is how the extension reaches this instance, and recording cannot work without it.
  4. The connect page opens and hands the connection over. If it does not, open the connect page yourself, show a connect code there, and paste it into the extension instead.

What unpacked means

An unpacked extension does not update itself: when this instance is upgraded, download the build again and choose Update on the extensions page. Chrome may also disable an unpacked extension after a browser update or a profile reload — turn it back on there, or load it again from this page.

Windows and macOS fleets can install this package for everyone through enterprise policy; nothing here is built for that.
